## 추가된 기능 (핵심 — 다른 AI 파악용)
- **`/novel` 페이지 신설** — 웹소설(『재의 장의사』) 운영 대시보드. role:admin 자동 보호(기존 미들웨어).
  - 요약 지표: 확정 화 수 / 평균 대사 비중(낮으면 경고색) / 미반영 피드백 수.
  - **화별 대사 비중 추이** 바 차트(순수 CSS, 15% 미만=서술 과다 붉은색). Chart.js 미도입(CSP·의존성 회피, Linear풍 절제 가이드 준수).
  - 확정 화 목록(제목/유형/분량/대사%/과용 표현).
  - 독자 피드백 입력 폼 + 목록 + 반영 토글 → novel 생성 파이프라인이 이 피드백을 읽어 반영.
- **`routes/novel.ts`** — Supabase(PostgREST) 프록시. english.ts 패턴 재사용. `NOVEL_SUPABASE_URL/SERVICE_KEY`(secret) 우선, `CONFIG_KV.novel_supabase_config` 폴백. novel은 invest와 같은 Supabase 프로젝트 재사용.
  - GET /api/novel/{episodes,metrics,feedback}, POST/PATCH /api/novel/feedback.
